# ClipAnimator

Turn any local video into a **dramatic animated recut**, then write **YouTube metadata** (title, description, tags) from facts you pass in — genre, team, player, moment.

This is a standalone tool. It is not Flag Goal Shorts. No physics arena, no 3D pitch, no YouTube upload.

## What you need

Same as a normal Python video script. Nothing else:

1. Python 3.11+
2. `ffmpeg` on PATH (`winget install ffmpeg`)
3. This folder’s `venv` + `pip install -r requirements.txt` (numpy, pygame, OpenCV)

An LLM key is **only** for metadata. The video still renders without one.

## Setup (Windows)

```powershell
cd C:\Users\User\Desktop\Side_Projects\ClipAnimator
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add **one** LLM backend so titles/tags are generated by a model:

```
GROQ_API_KEY=gsk_...          # free tier: https://console.groq.com
# or OPENAI_API_KEY=sk-...
# or OLLAMA_MODEL=llama3.2    # local, no cloud
```

If no key is set, metadata is still written from your `--genre` / `--about` facts (local fallback). Use `--require-llm` to fail instead.

## Generate a video + metadata

```powershell
.\venv\Scripts\Activate.ps1

python animate.py path\to\clip.mp4 --shorts `
  --genre football `
  --about "Manchester United, Cunha goal" `
  --player Cunha `
  --teams "Manchester United" `
  --moment "the surf / celebration" `
  --title "THE CUNHA SURF IS BACK"
```

Output:

- `out/<name>_cartoon_short.mp4` — the recut
- `out/<name>_cartoon_short.json` — `title`, `description`, `tags`, `tags_csv` (paste into YouTube)

### Example (Cunha Short)

```powershell
python animate.py "C:\Users\User\Downloads\the-cunha-surf-is-back-1920-ytshorts.savetube.me.mp4" --shorts --genre football --about "Manchester United, Matheus Cunha, the surf is back" --player "Matheus Cunha" --teams "Manchester United" --moment "Cunha surf celebration" --title "THE CUNHA SURF IS BACK"
```

## Flags

| Flag | What it does |
|------|----------------|
| `--style cartoon\|comic\|paint\|neon` | Drawing style (default `cartoon`) |
| `--drama low\|medium\|high` | Slow-mo / punch-in strength (default `high`) |
| `--shorts` | 1080×1920 cover-crop |
| `--max-seconds N` | Only the first N seconds of the source |
| `--keep-speed` | Stylize only, no time-warp |
| `--title "..."` | On-screen label in the video |
| `--genre` `--about` `--teams` `--player` `--moment` `--extra` | Facts for the LLM metadata |
| `--require-llm` | Exit if no LLM is configured |
| `--out path.mp4` | Output path |

Use clips you have the right to edit. The result is a stylized recut, not official broadcast footage.
